# libsvn iOS 编译验证 — 云编译步骤（无需 Mac）

## 1. 推送代码到 GitHub

在 PowerShell 中执行（把 `你的用户名` 换成你的 GitHub 用户名）：

```powershell
cd D:\MY\Code\IPAD

git add .
git commit -m "Add libsvn iOS cross-compile verification scripts"

# 在 GitHub 网页新建空仓库 iPadSVN，然后：
git remote add origin https://github.com/你的用户名/iPadSVN.git
git branch -M main
git push -u origin main
```

## 2. 触发编译

1. 打开 GitHub 仓库 → **Actions**
2. 左侧选 **Verify libsvn iOS Build**
3. 点 **Run workflow** → **Run workflow**
4. 等待约 **30～60 分钟**

## 3. 查看结果

| 结果 | 说明 |
|------|------|
| 绿色 ✓ | libsvn **可以**编进 iOS，Artifacts 里有 `libsvn.xcframework` |
| 红色 ✗ | 打开失败 job → 查看 **Build libsvn for iOS** 日志，把最后 50 行发给我 |

## 4. 下载产物

编译成功后，在该次 workflow 页面底部 **Artifacts** → 下载 `libsvn-ios-xcframework`。
